NEXCHAT app package

Files
- index.html            the whole app
- manifest.webmanifest  install info (name, icons, colours)
- sw.js                 lets the app open offline after the first visit
- icons/                app icons made from your logo
- package.json, capacitor.config.json   for building a real Android app
- MainActivity.java     replaces the generated one to block screenshots

Path A (phone or computer): host these files, then install from Chrome.
Path B (computer): build an Android app (APK) with Capacitor.
Full step-by-step instructions are in the chat.
